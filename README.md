# Titanic Survival Dashboard

## Project Overview
This project explores the Titanic passenger dataset using Python, PostgreSQL, Pandas and Streamlit.

## Technologies Used
- Python
- PostgreSQL
- Pandas
- Psycopg2
- Streamlit

## Database Details
Database: titanic_db
Schema: titanic_project

Tables:
1. passengers
2. survival_details
3. travel_details

Total records: 891 passengers.

## Dashboard Features
1. Passenger statistics and charts.
2. Passenger data explorer with filters.
3. Interactive SQL practice.
4. SQL knowledge quiz.
5. Missing-value analysis.

## How to Run

1. Install Python.
2. Install PostgreSQL.
3. Install the required libraries:

   pip install -r requirements.txt

4. Set PostgreSQL connection environment variables.
5. Run the application:

   streamlit run app.py

## Project Objective
To understand passenger survival patterns and practise SQL queries using a real-world dataset.
